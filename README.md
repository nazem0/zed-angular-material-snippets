# Angular Material v22 snippets for Zed

Zed extension with Angular Material `a-md-*` snippets (port of [hardikpthv.AngularMaterial](https://marketplace.visualstudio.com/items?itemName=hardikpthv.AngularMaterial)).

**Install:** Zed → Extensions → **Install Dev Extension** → this repo folder.  
Details: [INSTALL.md](./INSTALL.md).

Not a language server — snippets only. Complements Zed's `angular` / `angular-snippets` (general Angular), which do not include Material `a-md-*` prefixes.
